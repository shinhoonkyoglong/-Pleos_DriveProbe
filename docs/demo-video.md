# 시연영상 시나리오 — 「계속운전」

**한 줄 메시지:** 출발 전에 오늘 운전 조건을 확인하고, 주행 중 피로가 쌓이면 공조 → 음성 확인 → 휴게소 경유지 추가까지 차가 먼저 도와준다.

- 빌드: debug(에뮬레이터 시연 도구 사용), 앱 이름 '계속운전', **라이트 테마**
- 차량: Pleos 에뮬레이터 + Virtual Console(D단·80km/h·조향 입력). 실제 차량 신호로 판단하는 **REAL 모드**
- 총 길이 목표: 3~4분(주행 구간은 편집으로 줄임)

## 장면 구성

| # | 장면 | 화면 | 조작 | 자막/내레이션 예시 |
|---|---|---|---|---|
| 1 | 오프닝 | 계속운전 홈 | 없음 | "오늘도 운전해도 될까요?" |
| 2 | 운전 조건 | 홈 → [내 운전 조건] | 야간 운전 금지 켜기 → 저장 → 홈 | "해가 진 뒤에는 운전하지 않기로 했어요. 출발 마감 시각을 알려줘요" |
| 3 | 출발 판단(야간 경고) | 홈 '오늘 운전해도 되나요?' 카드 | 없음 | 출발 마감(일몰 − 예상 이동 시간 − 여유) 전: "오후 ○시 ○분까지 출발하면 돼요" / 지난 뒤: "오늘은 출발을 자제하세요" — 최종본(take6)은 마감 뒤라 경고가 나옴. "그래도 출발하면 주행 중 피로를 지켜봐요"로 이어 감 |
| 3-1 | 출발 전 반응 체크 | 홈 → [컨디션 체크] → [시작하기] | 브레이크 반응 5회(자동, `Prepare-Demo.ps1 -React`) → 결과 '평소와 비슷해요' → [확인] | "출발 전 15초, 브레이크 반응으로 오늘 컨디션을 확인해요" |
| 4 | 주행 도움 준비 | 홈 → [주행 도움] → [주행 도움 켜기] | 마이크 권한 허용 | "피곤해지면 공조와 음성으로 도와드려요" |
| 5 | 휴게소 확인 | [휴게소 설정] → [현재 경로의 휴게소 불러오기] → 기흥휴게소(부산방향) 선택·체크 → 저장 | 정차 중 | "가는 길의 다음 휴게소를 미리 확인해 둬요" |
| 6 | 출발 | 내비(안성휴게소 부산방향 안내) + 왼쪽 주행 화면 | 주행 시작 → 내비 화면으로 전환 | "출발" |
| 7 | 피로 감지 → 공조 | 하단 공조 바 'ON 공조 켜짐', 운전석 22.0° → 21.0° | 없음 | "졸음 징후가 보이자 공조를 켜고 온도를 낮춰요" |
| 8 | 음성 확인 (CAUTION) | 내비 화면 + TTS | 없음(자동 응답) | "괜찮으신지 음성으로 물어봐요" |
| 9 | 휴게소 제안 (DANGER) | 내비 화면 + TTS "다음 휴게시설은 기흥휴게소(부산방향)…" | 없음(자동 응답 '안내해 줘') | "더 피곤해지면 가까운 휴게소를 제안해요" |
| 10 | 경유지 추가 | 내비 경로에 기흥휴게소 경유지 | 없음 | "동의하면 내비에 바로 경유지로 들어가요" |
| 11 | 정차·주행 요약 | 정차 2초 뒤 앱이 앞으로 오며 주행 요약(피로 최고점·휴식 권고 1번·출발 전 반응·운전 조건 '지킴') | 자동 P → [확인] | "운전이 끝나면 오늘 주행을 바로 정리해 드려요" |
| 12 | 내 기록 (마무리) | 홈 → [내 기록]: 이번 주 요약(운전·조건 준수·휴식 권고·도움 받은 횟수) → 최근 주행 → 지난 주행 → 출발 전 반응 속도 → 최근 도움 기록 | 천천히 스크롤 | "운전과 도움 받은 기록이 쌓여 변화를 확인할 수 있어요" |

**3-1번 장면 자막:** "시연 환경에서는 Virtual Console로 브레이크 입력을 자동으로 넣었습니다."
**8·9번 장면 필수 자막:** "시연 환경에서는 에뮬레이터 마이크 제약으로 음성 답변(‘괜찮아요’, ‘안내해 줘’)을 자동 입력했습니다."

## 주행 타임라인 (`Prepare-Demo.ps1 -Drive`, 리허설 실측 2026-11-15)

| 주행 시간 | 일어나는 일 |
|---|---|
| 0:00 | D단 출발, 80km/h. 4초 뒤 내비가 앞으로. 왼쪽 주행 화면에 주변 차량 |
| 0:00~1:00 | 정상 주행 |
| 약 1:30 | MILD → 'ON 공조 켜짐', 운전석 22.0° → 21.0°, 풍량 증가 |
| 약 1:55 | CAUTION → 음성 질문 → '괜찮아요' 자동 응답(ANSWERED) |
| 약 2:35~3:10 | DANGER → "다음 휴게시설은 기흥휴게소(부산방향)…" → '안내해 줘' 자동 응답 → 내비 다음 목적지가 **기흥휴게소(부산방향) 25분·20km**로 바뀌고 진행 막대에 경유지 표시 |
| 약 3:30 | 자동 P 정차 → 2초 뒤 앱이 앞으로 오며 주행 요약 |

주행이 끝날 때 내비가 앞에 있으면 Android가 요약 화면 띄우기를 막는다. 앱은 막힌 요약을 기억했다가 앱이 앞으로 오는 순간 띄운다(`-Drive`가 정차 2초 뒤 앱 아이콘을 눌러 준다).

주행 중에는 시스템 정책상 계속운전 앱 화면이 "주행 중에는 사용할 수 없습니다"로 가려진다(의도된 동작). 그래서 주행 장면은 **내비 화면**으로 찍는다. 피로 단계는 화면에 띄우지 않고 공조 변화·음성·경유지로 보여준다.

## 촬영 전 준비 (매 테이크)

1. 에뮬레이터를 켜고(`emulator -avd Pleos_Connect_v2.1.0`) 백그라운드 무거운 프로그램은 끈다(화면 깜빡임·내비 음성 끊김 원인). Virtual Console은 P·속도 0.
2. 준비 한 번에(초기화·라이트 테마·차량 속도 권한·평소 기록 기준선·8주 시연 기록·내비 목적지 안성휴게소(부산방향)·음성 답변 자동 입력). 코드를 바꿨다면 `-Build`:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Prepare-Demo.ps1
   ```
3. 장면 1~5를 촬영하면서 앱에서 직접 설정한다: 운전 조건(무료도로 선호는 끔) → 반응 체크 → 주행 도움 켜기(마이크 허용) → 휴게소 확인.
   반응 체크는 [시작하기]를 누른 뒤 바로 실행:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Prepare-Demo.ps1 -React
   ```
4. 주행(장면 6부터, 약 3분 30초). 내비는 자동으로 앞으로 온다:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Prepare-Demo.ps1 -Drive
   ```

## 알고 있어야 할 것

- **음성 답변은 자동 입력**이다(debug 전용 `DEMO_ANSWERS`). 질문 TTS·동의 판정·경유지 추가는 실제 흐름이고, 이력에는 `responseTiming=DEMO_SCRIPTED_ANSWER`로 구분된다. 에뮬레이터 마이크는 `-allow-host-audio`로 켜도 무음이었고 원인은 미확인.
- 경유지 추가 후 SDK가 경유지 좌표를 비워 돌려줘 앱 기록상 '경유 항목 생성 확인 · 위치는 내비에서 확인'일 수 있다. 화면에는 내비 경로로 보여준다.
- 내비 음성이 끊기는 것은 에뮬레이터 오디오 출력 지연(underrun)이다. 필요하면 편집에서 음성을 별도 녹음본으로 교체한다.
- '무료도로 선호'는 꺼 둔다. 시연 경로가 경부고속도로(유료)라 켜면 조건과 어긋난다.
- 야간 경고는 실제 시각 기준이라 이번 시나리오에 넣지 않는다(11월 서울 일몰 약 17:20).
- 한 번 주행하면 기록과 경유지가 남는다. 재촬영 전에는 준비 2~3번을 다시 한다(목적지는 스크립트가 다시 넣는다).
