# 일출·일몰 기준값과 "야간" 정의 근거 (작업 #4a / #4b)

Pleos API가 아니라 외부 기준 자료를 정리한 노트다. 근거는 api-notes와 같은 방식으로 적었다.

## 1. 일출·일몰 기준값

### 출처
- 1순위: 한국천문연구원(KASI) 천문우주지식정보 "일출일몰시각계산" — https://astro.kasi.re.kr/life/pageView/9 (확인일 2026-11-09)
  - 페이지 안내 요약: 사용자가 입력한 좌표로 계산한다. 계산 오차는 1분보다 작다. 더 정확한 값은 역서(월별 해/달 출몰시각) 페이지를 쓰라고 한다. 참고문헌은 Meeus "Astronomical Algorithms"와 VSOP87이다. 지평선 고도 기준은 -0.8333°이며, 이는 천정각 90.833°와 같다.
  - **조회 방법 주의**: 이 브라우저에서는 페이지의 jQuery가 로드되지 않아 결과 칸이 비어 있었다. 그래서 code.jquery.com에서 jQuery 3.6.0을 주입했다. 그다음 페이지에 있는 KASI 계산 함수 `calcSunrise(경도, 위도)`를 해당 날짜(전역 `year/month/date/delta_t`)로 직접 호출해 화면 출력을 읽었다. 즉 KASI의 계산 코드를 그대로 실행한 결과이며, 폼 UI로 정상 조회한 화면은 아니다.
  - 결과는 분 단위로만 표시된다(초는 표시되지 않음). 표시값이 반올림인지 버림인지는 [불확실]하다.
  - KASI 페이지의 지명 "서울특별시" 기본 좌표는 폼 hidden 값 기준 **37.54980N, 126.9671E**다. 우리 테스트 좌표(37.5665, 126.9780)와 약 1.9 km 떨어져 있다. 두 좌표로 모두 계산해 보니 표시값(분)은 같았다(하지·동지·춘분 확인). 페이지 초기화 스크립트도 `calcSunrise(126.9780, 37.5665)`를 호출한다. 부산은 지명 선택 없이 좌표를 직접 넣었다.
- 2순위(교차검증): NOAA GML Solar Calculator — https://gml.noaa.gov/grad/solcalc/ (확인일 2026-11-09)
  - 페이지의 `calcSunriseSet(rise, jd, lat, lon, tz=9)` 함수를 직접 호출해 `timelocal`(분, 소수)을 받고 초 단위로 환산했다. NOAA 천정각도 90.833°다(`calcHourAngleSunrise` 소스에서 확인).
  - 검증: 페이지 기본 위치(39.833N, -98.583, CST)의 화면 일출값 07:12와 같은 함수로 계산한 07:12:21이 일치했다.
  - NOAA 계산기는 시민박명을 제공하지 않는다. 그래서 박명 값은 KASI 값만 있다.

## 2. "야간" 정의 근거 (고령 운전자 조건부 면허)

### 결론
- **고령 운전자 조건부 면허(야간 운전 제한)는 확정 제도가 아니다. 논의·추진 중이다.** 야간의 시간 정의(일몰~일출, 고정 시각, 시민박명 등)를 정한 공식 자료는 **찾지 못했다(근거 없음)**.
- 법령상 "밤"의 일반 정의는 있다. 도로교통법 제37조(차와 노면전차의 등화) 제1항 제1호는 밤을 "해가 진 후부터 해가 뜨기 전까지"로 정의하고 "이하 같다"로 법 전체에 적용한다. 이는 등화 의무 조문의 정의이며, 조건부 면허 조건으로 정해진 것은 아니다.
  - 출처: 국가법령정보센터 도로교통법 — https://www.law.go.kr/법령/도로교통법 ([시행 2026. 10. 13.] 법률 제22067호), 확인일 2026-11-09. [문서 확인]

### 현행 법령 상태 [문서 확인]
- 도로교통법 제80조 제3항: 시·도경찰청장은 신체 상태나 운전 능력에 따라 운전면허에 조건을 붙일 수 있다. 세부는 행정안전부령에 맡긴다.
- 도로교통법 시행규칙 제54조 제2항: 조건은 자동차 구조 한정(자동변속기, 다륜형 원동기장치자전거, 손 조작 장치, 장애 맞춤 차량), 보조수단 사용(의수·의족·보청기), 청각장애인 표지·볼록거울 부착으로 한정된다. **시간대(야간)·도로 종류(고속도로) 제한 조건은 없다.**
  - 출처: https://www.law.go.kr/법령/도로교통법시행규칙 (확인일 2026-11-09)
- 제80조의2와 제85조의3의 "조건부 운전면허"는 음주운전 방지장치 부착 조건부 면허다. 고령 운전자 제도와는 관련이 없다.

### 추진 상황 (언론 보도, 공식 원문 아님) [불확실 — 2차 출처]
- 매일신문 2026-10-10 보도(https://www.imaeil.com/page/view/2026101006531725206)에 따르면 다음과 같다.
  - 경찰청은 2027년 하반기 도입을 목표로 한다. 검토 중인 조건에는 야간 운전 금지, 고속도로 운전 금지 등이 있다.
  - 근거가 될 도로교통법 개정안은 국회 상임위 심사를 앞두고 있다(미통과).
  - 도로교통공단은 2026년 2월부터 운전능력진단시스템을 시범운영하고 있다.
  - 야간의 시간 정의는 언급하지 않았다.
- 과거 보도: YTN 2019-03-18(https://www.ytn.co.kr/_ln/0103_201903180539056604), 대구MBC(https://dgmbc.com/article/_ub6UBsdlTSlwxEXKv), 머니투데이 2023-03-14(https://www.mt.co.kr/estate/2023/03/14/2023031317485110564), 파이낸셜뉴스 2024-07-08(https://www.fnnews.com/news/202407081201472493). 모두 "야간 운전 제한"이라는 표현만 쓰고 시간 정의는 없다.
- 경찰청 보도자료나 개정안 원문(의안정보시스템)은 이번에 확인하지 못했다. [불확실]

### #4b 설계 시사점 (근거 범위 안에서만)
- 법령에 있는 유일한 "밤" 정의는 일몰~일출(도로교통법 제37조)이다. 일몰을 기본 경계로 쓰는 것은 이 정의와 맞는다.
- 조건부 면허의 야간 정의는 확정되지 않았다. 따라서 경계 기준(일몰 / 시민박명 종료 / 고정 시각)은 `DepartureConfig` 설정값으로 두는 것이 안전하다. 기본값을 무엇으로 할지는 제품 결정이며 법적 근거는 없다.
- 일몰 기준을 쓰면 시민박명 종료보다 약 26~31분(서울·부산, 위 표 기준) 일찍 "야간"이 된다. 보수적인 방향이다.
